### 模块关闭时的路由行为

| 模块 | 关闭后 |
|---|---|
| `log` | `/logs*` → 404；首页日志区块消失 |
| `portfolio` | `/portfolio*` → 404；首页作品区块消失 |
| `timeline` | `/timeline` → 404；`/about` 中的经历区块同时隐藏 |
| `article` | `/articles*` → 404；首页文章区块消失；RSS 仅输出日志 |
| `about` | `/about` → 404；导航移除；联系方式彻底不可达 |

> **特例**：`timeline` 关闭时，「关于我」页面的工作经历区块**一并隐藏**（因为二者共用 `TimelineItem` 数据）。这一点必须在后台的关闭确认清单里说明。

## 2. 三端断点定义

```ts
// Tailwind v4：src/app/globals.css @theme定义断点（示意）
{
  xs:  '380px',   // 小屏手机（iPhone SE）
  sm:  '640px',   // 大屏手机横屏 / 小平板竖屏
  md:  '768px',   // 平板竖屏  ★ 平板临界点
  lg:  '1024px',  // 平板横屏 / 小笔记本  ★ PC 起点
  xl:  '1280px',  // 桌面
  '2xl': '1536px' // 大桌面
}
```

### 三端布局策略矩阵

| 维度 | 移动 `< 768px` | 平板 `768–1023px` | PC `≥ 1024px` |
|---|---|---|---|
| **导航** | 顶部 Logo + 汉堡；**底部 Tab Bar**（首页/日志/作品/文章/关于） | 顶部横向导航（完整文字） | 顶部横向导航 + 右侧主题切换/搜索 |
| **内容宽度** | 100%（padding 16px） | max-width 720px 居中 | 文章类 max-width 720px；列表类 max-width 1200px |
| **列表布局** | 单列卡片 | 双列网格 | 文章单列 / 作品三列 / 日志双列 |
| **文章详情** | 单栏，目录折叠为顶部分段导航 | 单栏 + 抽屉 TOC | **双栏**：正文 + 右侧 sticky TOC |
| **作品详情** | 图集横向滑动 + 信息纵向堆叠 | 图集网格 + 信息两栏 | 左图右信息（sticky） |
| **时间轴** | 左侧单线，内容右对齐 | 左侧单线、单列 | 中线对称 + 年份吸附 |
| **关于我** | 全部分区纵向堆叠，技能用进度条 | 优势 2 列，技能 2 列 | 优势 3 列，技能 2 列 + 经历侧栏 |
| **页脚** | 精简（版权 + 社交图标） | 两栏 | 三栏（简介 / 导航 / 社交） |
| **搜索** | 全屏浮层 | 全屏浮层 | 顶部下拉面板 |
| **触控目标** | ≥ 44×44px | ≥ 44×44px | ≥ 32×32px（鼠标精度更高） |

### 移动端特殊处理

| 项 | 处理 |
|---|---|
| 底部 Tab Bar | 固定底部，`padding-bottom: env(safe-area-inset-bottom)` 适配刘海屏；滚动时下滑隐藏、上滑显示 |
| 内容不被遮挡 | 主内容区 `padding-bottom: calc(64px + env(safe-area-inset-bottom))` |
| 图片 | `next/image` 的 `sizes` 按断点声明，移动端不下载桌面大图 |
| 长文阅读 | 正文字号 16px→17px，行高 1.75，段间距加大 |
| 代码块 | 横向滚动，不换行；右上角「复制」按钮常显（移动端无 hover） |
| 表格 | 一律转卡片式，不横向滚动 |
| 手势 | 文章详情支持左右滑动切换上/下一篇（可选，需 `prefers-reduced-motion` 尊重） |
| 悬浮元素 | 移动端取消所有 hover-only 交互，改为常显或点击触发 |

### 平板特殊处理

平板是最容易被忽略的中间态，重点：

- **触屏 + 可能横竖屏切换**：布局必须使用流式断点，不能用固定像素
- 横屏（`lg`）时把平板当作 PC 处理，竖屏（`md`）当作放大的移动端
- **无 hover**：所有依赖 hover 的下拉菜单，在 `md` 断点下改为点击触发（用 `@media (hover: hover)` 判断而非屏幕尺寸）

```css
/* 正确的做法：按能力检测，而不是按尺寸猜 */
@media (hover: hover) and (pointer: fine) {
  .card:hover { transform: translateY(-4px); }
}
```

## 3. 导航设计

### PC / 平板 ≥ 768px · 顶部导航

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  Puly                                          日志  作品集  时间戳  文章  关于我   🔍  ☾ │
└─────────────────────────────────────────────────────────────────────────────┘
   ↑ Logo，回首页      ↑ 由 Module 表动态生成，按 navOrder 排序    ↑ 搜索  ↑ 主题
```

**行为**
- 滚动超过 80px 后：背景加毛玻璃 + 阴影，高度从 72px 收窄到 60px
- 当前路由高亮：文字变强调色 + 底部 2px 指示条（CSS短过渡，减弱动态时立即切换）
- 模块关闭后该项自动消失（数据来自 `moduleService.listVisible()`）
- 平板（`md`–`lg`）隐藏搜索框文字只留图标，节省空间

### 移动 < 768px · 顶部 + 底部 Tab

```
┌───────────────────────────────┐        顶部：Logo + 汉堡（抽屉：搜索/主题/全部导航）
│  Puly                    ☰    │
├───────────────────────────────┤
│                               │
│        （内容区）              │
│                               │
│                               │
├───────────────────────────────┤        底部 Tab Bar（固定）
│   🏠      📓      💼     📄   │        首页 / 日志 / 作品集 / 文章
│  首页    日志    作品    文章  │        active 项：图标+文字变强调色，图标上移 2px
└───────────────────────────────┘
```

**移动底部 Tab 规则**
- 最多 5 项，超出时把第 5 项做成「更多」（抽屉打开完整导航）
- 模块关闭后 Tab 项自动移除；若总项数 ≤ 4 则平均分布
- 只在 `(site)` 路由组显示，`(admin)` 不显示
- 用 `position: fixed` + `backdrop-blur`，`z-index` 低于弹窗/抽屉

- 全部区块都关闭时，Hero 下方显示引导文案 + 社交链接（不留白屏）

> `config` 的完整键名规范见 [01-architecture.md §7](01-architecture.md)。

**卡片信息层级**（严格按此顺序，保证扫视效率）

1. 封面图（16:9，`object-cover`）
2. 标题（粗体，1 行截断）
3. 一句话描述（2 行截断）
4. 技术栈徽章（最多显示 3 个，超出显示 `+2`）

**"Skills" 类型作品**：这类不是项目而是能力展示，卡片样式略不同 —— 用图标代替封面图，描述里写"这项能力我做到什么程度"。

## 6. 状态设计

每个列表/详情页必须显式设计四种状态，不能只画「有数据」的样子。

| 状态 | 列表页 | 详情页 |
|---|---|---|
| **加载中** | 骨架屏，**保持与真实卡片相同的高度**（避免 CLS） | 骨架屏：标题条 + 段落条 + 图片占位 |
| **空数据** | 插画 + 「这个栏目还没有内容，敬请期待」+ 引导去别处 | — |
| **筛选无结果** | 「没有符合条件的内容」+ [重置筛选] 按钮 | — |
| **错误** | 错误提示 + [重试] 按钮，**导航与页脚保持可用** | 错误页 + 返回入口 |
| **404 / 模块关闭** | — | 4.11 的 404 页（文案可区分） |

## 7.1 动效层（一期version2）
站点layout是根html/body内部容器，不重复输出html/body。服务端取得08合法配置并在站点容器注入强度/装饰/交互属性；默认editorial+none，只允许none/tint静态装饰。首屏Hero全部CSS，首屏正文可读；离屏区块按需MotionRuntime，卸载清理。后台普通页不加载，动效预览页按需使用同一运行时。

系统reduce最高优先，移动按mobileIntensity；访客关闭立即生效，完整档不能覆盖系统偏好。无连续背景/Canvas/光标。字段及合法值见08，不下发预设工具。JS失败/关闭不能隐藏内容。


## 8. 可访问性（A11y）

| 项 | 要求 |
|---|---|
| 语义标签 | `header` `nav` `main` `article` `aside` `footer` 正确使用，每页仅一个 `h1` |
| 键盘可达 | 所有交互元素可 Tab 到达，`:focus-visible` 有清晰轮廓（不用 `outline: none`） |
| 跳转链接 | 页面首个可聚焦元素是「跳到主内容」 |
| 图片 | `alt` 必填（装饰图用 `alt=""`）；上传时后台强制填 alt |
| 色彩对比 | 正文对比度 ≥ 4.5:1，大字 ≥ 3:1（亮暗两套主题都要验） |
| 图标 | 纯图标按钮必须有 `aria-label` |
| 动效 | 强制尊重 `prefers-reduced-motion`（优先级高于后台配置）；闪烁 ≤ 3Hz；装饰层 `aria-hidden`；内容默认可见，不因动效失败而空白 —— 详见 [08-motion-system.md §7](08-motion-system.md) |
| 表单 | 每个输入有 `<label>`；错误用 `aria-describedby` 关联；`aria-invalid` |
| 弹窗/抽屉 | focus trap，`Esc` 关闭，关闭后焦点回到触发元素 |
| 屏幕阅读器 | 列表用 `ul/li`；状态变化用 `aria-live="polite"` 播报 |
| 语言 | `<html lang="zh-CN">` |

## 9. SEO 元数据矩阵

| 页面 | title | description | OG image | 结构化数据 |
|---|---|---|---|---|
| 首页 | `{site.name} · {site.description}` | `site.description` | 站点主视觉 | `Person` + `WebSite` |
| 文章列表 | `文章 · {site.name}` | 「认真写的一些东西…」 | 默认 OG | `CollectionPage` |
| 文章详情 | `{title} · {site.name}` | `summary` 或 `seoDescription` | `ogImage` 或 `coverImage` | `BlogPosting` + `BreadcrumbList` |
| 日志列表 | `日志 · {site.name}` | 栏目导语 | 默认 OG | `CollectionPage` |
| 日志详情 | `{title} · 日志 · {site.name}` | `summary` | `coverImage` | `BlogPosting` |
| 作品集 | `作品集 · {site.name}` | 栏目导语 | 默认 OG | `CollectionPage` |
| 作品详情 | `{title} · 作品集 · {site.name}` | `description` | `coverImage` | `CreativeWork` |
| 时间戳 | `时间戳 · {site.name}` | 「我走过的每一步」 | 默认 OG | `BreadcrumbList` |
| 关于我 | `关于我 · {site.name}` | `headline` | `avatar` | `Person` + `ProfilePage` |
| 搜索 | `搜索：{q} · {site.name}` | — | — | **`noindex`** |
| 404 | `页面不存在 · {site.name}` | — | — | **`noindex`** |

**其他 SEO 要素**
- `<link rel="canonical">` 每页显式声明，避免参数页重复收录
- `sitemap.xml` 动态生成，**只含已发布且模块启用**的 URL；关闭模块自动移除
- `rss.xml` 全站订阅；每模块可选独立 feed（`/logs/rss.xml`）
- OG 图用 `next/og` 的 `ImageResponse` 动态生成（标题 + 站点名 + 渐变背景），无需手工做图
- `robots.txt`：`Disallow: /admin` `Disallow: /api` `Disallow: /search`
- 后台路由加 `<meta name="robots" content="noindex, nofollow">`

## 10. PWA 与离线（二期，一期不实现）
