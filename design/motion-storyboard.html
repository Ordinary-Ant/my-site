动效分镜表

Background

背景动效 · 6 种类型

固定定位的装饰层，z-index: -1、pointer-events: none，不占文档流、不遮挡点击、不阻塞 LCP。

0 KB JS
① 流动渐变 gradient-flow 24s 循环 · 默认预设「呼吸渐变」用它
参数：angle 135° · speed 24s · blur 80px · opacity 35% · noiseOverlay 开 · parallax 关　│　 实现：::before + transform 关键帧（只动 transform/opacity，走 GPU 合成层）　│　 作用范围：默认仅首页
② 极光 aurora 38s 循环 · 建议仅首页
实现：3 层 radial-gradient 各自不同速度　│　成本：3 个合成层，是所有背景类型里最重的纯 CSS 方案　│　注意：暗色主题下效果远好于亮色，亮色下建议提高 blur 降低 opacity
③ 光斑 blur-blob 34s
两团模糊色斑独立漂移，周期错开，永不同步 —— 视觉上不会"循环感"太重。
④ 网格 grid 18s 线性
双向网格沿对角线缓慢漂移。用 background-position 驱动，成本极低。
⑤ 星空 stars 纯 CSS · 0 KB JS
实现：多层 radial-gradient 点阵 + opacity 关键帧。**不用 Canvas**，所以是 0 KB JS。暗色主题专用。
⑥ 粒子 particles +12 KB JS · 仅第 3 层
加载条件（四重门槛）：配置开启 且 非移动端 且 hardwareConcurrency > 4 且 未触发降级。
实现：手写 Canvas 2D，禁止引入 three.js（那一个库就 600 KB）。最大 200 点。

Degradation

六级降级链

按优先级自上而下生效。第 ① 级的优先级高于后台配置 —— 用户系统里的无障碍偏好，站点无权覆盖。

①
系统「减弱动态效果」 最高优先级
强制 intensity = off，背景层 display: none，所有动画时长压到 0.01ms。后台配置被覆盖，且后台 UI 上不可关闭此项。
②
移动端（< 768px）
降档到 mobileIntensity（默认 subtle）。重动效一律不加载 —— 不是"关掉"，是连 chunk 都不下载。
③
设备能力检测
hardwareConcurrency ≤ 4 或 deviceMemory ≤ 4 或省流量模式 → 再降一档。
④
FPS 守护
连续 2 秒帧率 < 45 → 关闭重动效，并写 sessionStorage 记住本次会话，避免反复降级又升级造成抖动。不弹任何提示打扰访客。
⑤
省电模式 / 减少透明度偏好
关闭所有 blur 类背景 —— 大面积 filter: blur 是最耗电的动效，尤其在 OLED 屏上。
⑥
页面不可见
visibilitychange: hidden → 暂停所有 rAF 循环与 Canvas 绘制。切回来再恢复。
访客端的手动兜底

页脚有一个极小的图标按钮，点击在三档间循环，状态写入 localStorage。这是给访客的最终控制权，也满足 WCAG 2.2.2。

后台如何知道发生了降级

动效配置页右侧有一个「降级状态」卡片，如实显示四项检测的当前状态。当预览窗自身触发 FPS 降级时，会显示提示 —— 让你知道真实访客看到的是什么，而不是只在你的高配机器上好看。
